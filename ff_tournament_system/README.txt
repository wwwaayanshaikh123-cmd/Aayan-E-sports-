AAYAN ESPORTS - FREE FIRE TOURNAMENT SYSTEM

WHAT IS INCLUDED
- Tournament landing page
- Squad registration form
- 12-team registration limit
- Duplicate team-name check
- Rules section
- Match schedule
- Points table
- Registered teams table
- Local browser storage (data stays in that browser)

HOW TO RUN IN VS CODE
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser.
   OR install/use VS Code Live Server and click "Go Live".
4. Test registration from the Register Team section.

IMPORTANT
This version is a front-end/local prototype. Registrations are stored in the browser's localStorage, so they are NOT automatically shared with another phone or computer.

POINT SYSTEM EXAMPLE
Placement: 1st=12, 2nd=9, 3rd=8, 4th=7, 5th=6, 6th=5,
7th=4, 8th=3, 9th=2, 10th=1, 11th=0, 12th=0.
Kills: 1 point per kill.

Change the points to match the official rules of the specific tournament/event you are running.
